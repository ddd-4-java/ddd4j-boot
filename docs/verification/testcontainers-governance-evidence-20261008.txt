四、API 兼容性检查结论（决定 9 个模块是否可转换）
--------------------------------------------------------------------------------
测试源码 import 全部为经典包名（org.testcontainers.containers.* /
org.testcontainers.junit.jupiter.* / org.testcontainers.utility.*）。
javap 实测（本地仓库 jar）：
  - org.testcontainers:kafka:1.20.6
      KafkaContainer(DockerImageName) 构造器存在；getBootstrapServers() 存在
  - org.testcontainers:rabbitmq:1.20.6
      RabbitMQContainer(DockerImageName) 构造器存在；getAmqpPort() 存在；
      execInContainer 来自 core GenericContainer（1.21.4 存在）
  - org.testcontainers:localstack:1.20.6
      LocalStackContainer(DockerImageName) 构造器存在；
      withServices(LocalStackContainer.Service...) 存在；
      getEndpointOverride(Service) 返回 java.net.URI 存在
  - org.testcontainers:junit-jupiter:1.21.4
      @Testcontainers(disabledWithoutDocker=...) / @Container 存在
  - core GenericContainer / Wait / DockerImageName / MountableFile /
    Container.ExecResult：1.21.4 均存在（unzip 核对 GenericContainer.class）
  - 其余 6 模块（activemq/mqtt-mica/nats/pulsar/redis-stream/rocketmq）仅用
    GenericContainer + Wait + DockerImageName + MountableFile，全部 core API
结论：未发现任何 2.x-only API，9 个模块全部可转换，0 个模块因 API 不兼容停止。
备注：本地仓库暂无 kafka/rabbitmq/localstack 的 1.21.4 二进制（仅 1.20.6），
      1.21.4 在构建时由编排者统一拉取；1.20.6 与 1.21.4 同属 1.x，上表 API
      签名在 1.21.4 保持兼容（1.x 契约稳定）。

   模块级声明全部无 <version>，统一由钉版清单解析 => 1.21.4。

   mysql:1.21.4 -> jdbc:1.21.4 -> database-commons:1.21.4（来自 mysql pom）；
   testcontainers-bom:2.0.5 与 ddd4j-dependencies BOM 均不管理 1.x 命名的

   junit-jupiter/kafka/rabbitmq/localstack 的传递依赖仅为 core testcontainers
   （已被钉 1.21.4）。
E. 双版本共存（治理前）的 jar 级证据
   - org/testcontainers/junit/jupiter/Testcontainers.class 等同名类同时存在于
     junit-jupiter-1.21.4.jar（10 个 class）与 testcontainers-junit-jupiter-2.0.5.jar
     （10 个 class）——同 FQN 双版本。
   - org/testcontainers/containers/KafkaContainer.class 同时存在于 1.x kafka 与
     testcontainers-kafka-2.0.5.jar；
     org/testcontainers/containers/RabbitMQContainer.class 同时存在于 1.x rabbitmq
     与 testcontainers-rabbitmq-2.0.5.jar；
     org/testcontainers/containers/localstack/LocalStackContainer.java 同时存在于
     1.x localstack 与 testcontainers-localstack-2.0.5（sources jar）——
     与 core 1.21.4 的 org.testcontainers.containers.* 包共享，构成类分裂。
   本地仓库实存 testcontainers-junit-jupiter / -kafka / -rabbitmq / -localstack
   的 2.0.3 与 2.0.5 版本目录，佐证治理前 2.x 确已参与解析。
结论：治理后 ddd4j-boot 4.0.x 全部 org.testcontainers 依赖（6 个直接 artifactId
+ 传递 jdbc/database-commons）唯一解析为 1.21.4，双版本漂移消除。
